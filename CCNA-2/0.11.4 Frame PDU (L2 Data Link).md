## 2. 🗺️ Visualization — the Ethernet frame (with the optional VLAN tag)

```
   Recall (Part 0): the frame wraps the L3 packet and adds a TRAILER (FCS).
   The FRAME is the last "envelope" before bits go on the wire.

 ┌──────────┬─────┬──────────┬──────────┬───────────┬─────────┬────────────┬──────┐
 │ Preamble │ SFD │ Dest MAC │ Src MAC  │[802.1Q tag]│EtherType│  Payload   │ FCS  │
 │   7 B    │ 1 B │   6 B    │   6 B    │  (4 B opt) │  2 B    │ 46–1500 B  │ 4 B  │
 └──────────┴─────┴──────────┴──────────┴───────────┴─────────┴────────────┴──────┘
   └── 8 B L1 sync ──┘  └──────────────── covered by FCS ("the frame") ─────┘  ┊IFG┊
   (usually not counted        min 64 B (Dest MAC → FCS), max 1518 B          12 B
    in "frame size")           (+4 B with 802.1Q tag → 1522 B)                gap

   With a tag, payload minimum drops to 42 B (the tag eats 4 of the 46).
```

**One-line map:** the frame is the **local-delivery envelope** — destination/source **MAC** up front, an **FCS trailer** to catch corruption, an optional **4-byte VLAN tag**, and hard **size limits** born of Ethernet's physics. 📦

---

## 3. ⚡ TL;DR

- 🟢 **PDU = frame.** Header (14 B untagged) + payload (46–1500 B) + **FCS** trailer (4 B). On the wire it's preceded by **Preamble + SFD** (8 B) and followed by the **IFG** (12 B).
- 🟢 **MAC addresses:** 48-bit, **OUI + device**. Destination first, then source. **Broadcast = FF:FF:FF:FF:FF:FF.**
- 🟢 **EtherType** special values: **0x0800 IPv4, 0x86DD IPv6, 0x0806 ARP, 0x8100 = 802.1Q tag.** (Values ≤ 0x05DC = a **Length** field, legacy 802.3.)
- 🟢 **802.1Q tag (4 B):** **TPID = 0x8100** + **TCI** = **PCP (3 b)** + **DEI (1 b)** + **VID (12 b)**. Usable VLANs **1–4094** (0x000 & 0xFFF reserved).
- 🟢 **FCS = CRC-32**: **detects & discards** corrupt frames (no correction).
- 🟢 **Sizes:** min **64 B** (< 64 = **runt**), max **1518 B** (**1522** tagged); > max = **giant**; **jumbo ≈ 9000 B** if configured.
- 🟢 **Native VLAN** frames traverse a trunk **untagged**.

---

## 4. 🎯 Importance — the problem *first*

**❗ The underlying problem:** the physical layer just pushes **bits**. To make those bits usable on a shared local wire you need: a way to know **where a frame starts/ends** (framing), **which device** on this link should grab it (local addressing), a check that **noise didn't corrupt it** (error detection), and — in modern networks — a way to run **many virtual LANs over one physical link** (VLAN tagging) and **prioritise** time-sensitive traffic (CoS). The frame header/trailer encodes exactly these. 🎯

**✅ What the frame does:** **Preamble/SFD** synchronise the receiver's clock and mark the start; **Dest/Src MAC** address the local hop and let the switch learn; **EtherType** says what's inside; the **802.1Q tag** carries VLAN identity + priority; the **FCS** catches corruption; **size limits** keep shared-media timing and buffers sane. 🧠

**Engineer's "why it matters":** the frame is what a **switch** reads and what **VLANs/trunks** manipulate. Rising **CRC/FCS errors**, **runts/giants**, a **native-VLAN mismatch**, a **VLAN-hopping** double-tag attack, or an **MTU/jumbo** mismatch are all read in this PDU. It's the daily bread of campus networking. 🔧

---

## 5. 📋 Description (the essentials)

- 🟢 **PDU:** frame. Wraps the L3 **packet**; adds a header **and** a trailer (FCS).
- 🟢 **Two sublayers feed it (from 0.7):** **LLC** (interface up to L3) + **MAC** (framing, addressing, FCS).
- 🟢 **Ethernet II framing** dominates (EtherType-based); legacy **802.3** uses a Length field + LLC.
- 🟢 **Optional 802.1Q tag** inserts 4 bytes for VLAN + priority.
- 🟢 **Scope:** one local link / one hop; the frame is **rebuilt at every router hop** (Part 0).

## 6. 🔬 How It Works — every field, bit by bit

### 6.1 🧬 Ethernet II frame — all fields (IEEE 802.3) 🟢🔵

| Field | Size | Holds / special values |
|---|---|---|
| **Preamble** | 7 B | `10101010`×7 — clock sync (L1) |
| **SFD** | 1 B | `10101011` — "frame starts now" |
| **Destination MAC** | 6 B | who on this link receives it |
| **Source MAC** | 6 B | who sent it (switch **learns** this) |
| **[802.1Q tag]** | 4 B (opt) | VLAN + priority (see §6.5) |
| **EtherType/Length** | 2 B | ≥0x0600 = type; ≤0x05DC = length (see §6.4) |
| **Payload** | 46–1500 B | the L3 packet (padded up to 46 if smaller) |
| **FCS** | 4 B | CRC-32 error check (trailer) |

*(Preamble + SFD are line-level sync and usually **excluded** from the counted "frame size"; the FCS covers Dest-MAC → Payload.)*

### 6.2 ⏱️ Preamble & SFD — the run-up (mostly L1) 🔵

- **Preamble** (7 B of alternating `1010…`) lets the receiver **lock its clock** to the incoming bit stream. 
- **SFD** (`10101011`) — the change in the last two bits signals **"the actual frame begins on the next bit."** 
- These aren't part of the FCS-protected frame; think of them as the starting gun. 🏁

### 6.3 🏷️ MAC address anatomy 🟢🔵

```
   48-bit MAC:  AA : BB : CC : DD : EE : FF
                └──── OUI (24b) ───┘ └─ device (24b) ─┘   vendor + NIC

   First octet, low two bits:
     bit0 = I/G : 0 = unicast (individual) 🎯 | 1 = multicast/broadcast (group) 🌊
     bit1 = U/L : 0 = universal (OUI/burned-in) | 1 = locally administered
   FF:FF:FF:FF:FF:FF = BROADCAST (all ones)
```
- **I/G** — Individual/Group bit — [internal](./terms/mac-address.md#ig-bit) · [external](https://standards.ieee.org/products-programs/regauth/oui/)
- **U/L** — Universal/Local bit (set on randomised/locally-assigned MACs) — [internal](./terms/mac-address.md#ul-bit) · [external](https://standards.ieee.org/products-programs/regauth/oui/)
- Flat, not hierarchical → local-only, not routable (that's why IP/L3 exists). 🗺️

### 6.4 🔢 EtherType / Length — the clever dual-purpose field 🟢

- **≥ 0x0600 (1536)** → **EtherType**: names the payload protocol. 
- **≤ 0x05DC (1500)** → **Length**: legacy IEEE 802.3 (used with an 802.2 LLC header). 
- Since 1500 < 1536, the two coexist unambiguously on one wire. 🎯

**Special EtherType values 🟢:**
| Value | Meaning |
|---|---|
| **0x0800** | IPv4 |
| **0x0806** | ARP |
| **0x86DD** | IPv6 |
| **0x8100** | 802.1Q VLAN tag |
| 0x88A8 | 802.1ad (QinQ S-tag) |
| 0x8847 | MPLS unicast |
| 0x8863/0x8864 | PPPoE discovery/session |

### 6.5 🏷️ The **802.1Q tag** — dissected to the bit 🟢🔵

When present, the 4-byte tag sits **between Source MAC and EtherType** (in the EtherType position — that's how a device knows it's tagged):
```
   ┌────────────────────┬──────────────── TCI (16 b) ───────────────┐
   │  TPID (16 b)       │ PCP (3 b) │ DEI (1 b) │      VID (12 b)    │
   │  = 0x8100          │           │           │                   │
   └────────────────────┴───────────┴───────────┴───────────────────┘
   A device reading 0x8100 in the EtherType slot knows: "next 2 bytes = TCI,
   and the REAL EtherType comes AFTER the tag."
```
- **TPID** (16 b) — **0x8100** marks a standard 802.1Q tag. 🟢
- **PCP** (3 b) — **Priority Code Point** (802.1p) = **CoS**, values **0–7**: 🟢🔵
  | PCP | 802.1p class | Note |
  |---|---|---|
  | **1** | Background | **lowest** ⬇️ |
  | **0** | Best Effort | **default** |
  | 2 | Excellent Effort | |
  | 3 | Critical Apps | |
  | 4 | Video | < 100 ms |
  | 5 | Voice | < 10 ms |
  | 6 | Internetwork Control | |
  | 7 | Network Control | **highest** ⬆️ |
  > ⚠️ **The famous quirk:** **PCP 1 (Background) is *lower* than PCP 0 (Best Effort)** — not a clean 0→7 ramp. Memorise it. 🔵
- **DEI** (1 b) — **Drop Eligible Indicator** (formerly **CFI**): "drop me first under congestion." 🔵
  - **CFI** — Canonical Format Indicator (legacy; 0 for Ethernet) — [internal](./terms/dot1q.md#cfi) · [external](https://standards.ieee.org/ieee/802.1Q/6844/)
- **VID** (12 b) — **VLAN Identifier**, values **0–4095**: 🟢
  | VID | Meaning |
  |---|---|
  | **0x000 (0)** | reserved — **priority tag** (802.1p only, no VLAN) |
  | **1** | default VLAN (often mgmt; vendor-specific) |
  | **2–4094** | usable VLANs |
  | **0xFFF (4095)** | reserved — must not be used |
  → **4094 usable VLANs.**

**Native VLAN 🟢:** on a trunk, frames belonging to the **native VLAN** are sent **untagged**; an **untagged** frame arriving on a trunk is placed in the receiver's native VLAN. A **native-VLAN mismatch** between two ends silently merges VLANs — a classic bug (and a security risk).

**QinQ / 802.1ad (double tagging) 🔵:** provider edges add an **outer S-tag** (TPID **0x88A8**) around the customer's inner **C-tag** (0x8100) to carry customer VLANs across a provider core. Two tags = 8 bytes → raises max frame to **1526 B**.
- 🔒 **Security note:** malicious **double-tagging** is the basis of **VLAN-hopping** attacks — mitigated by not using VLAN 1 as native and by explicit tagging.

### 6.6 🧮 FCS / CRC-32 — detect, then discard 🟢

- The sender runs **CRC-32** over Dest-MAC → Payload and stores the 4-byte result in the **FCS**. The receiver recomputes and compares; **mismatch → drop the frame.** 
- Ethernet **does not retransmit** — recovery (if needed) is **TCP's** job (L4). So L2 = "detect & discard," not "detect & correct." 🎯
- 🟢 Rising **CRC/FCS errors** on an interface = a **physical** problem (bad cable/connector/transceiver, or a duplex mismatch).

### 6.7 📏 Frame sizes, runts, giants, jumbo, and the IFG 🟢🔵

```
   64 B ─────────────── 1518 B (1522 tagged) ─────── ~9000 B
    │                       │                            │
   MIN (Dest MAC→FCS)      MAX standard               JUMBO (if enabled)
   < 64 = RUNT 🗑️          > max = GIANT/oversize 🗑️
```
- **Min 64 B:** payload padded to **46 B** if smaller; frames < 64 are **runts** (from collisions/duplex issues) and dropped. *(The 64-byte floor comes from CSMA/CD slot-time — see 0.8/0.7.)* 🔵
- **Max 1518 B** (header 14 + payload 1500 + FCS 4); **1522** with a VLAN tag; **1526** with QinQ. Over the limit = **giant**. 
- **Jumbo frames** (~9000 B payload) boost efficiency in data centers/storage — but **both ends and every hop must agree**, or you get drops. 🔵
- **IFG** (Inter-Frame Gap): a mandatory idle of **96 bit-times = 12 bytes** between frames, letting receivers recover. ⏸️

### 6.8 👁️ Reading/writing order at L2 — who, when, why 🟢

- **On send:** L2 wraps the L3 **packet**: prepend the header (MACs, EtherType), append the **FCS**, then L1 sends bits. So L2 is written **last** of the header-adding layers (outermost header + trailer). 
- **On receive:** L2 is read **first** — check dest MAC (is it me / broadcast / multicast?), **verify FCS** (drop if bad), read **EtherType** (→ hand payload to IPv4/IPv6/ARP), strip header+trailer. 
- **At a switch (the star):** read **destination MAC** → **exact-match** MAC-table lookup → **forward** to that port (or **flood** if unknown/broadcast). It may **add/strip the 802.1Q tag** (access↔trunk) and then **recompute the FCS**. It does **not** touch L3. ⚡
- **At a router:** it **discards the whole frame** and builds a **brand-new one** (new MACs, new FCS) for the next hop; only the **packet** inside survives. 🔁

### 6.9 🔌 Handoff (up & down)

- **Down:** the frame's bytes go to L1 to become **bits/signals** (next: 0.11.5). 
- **Up:** after FCS check, **EtherType** hands the payload to the right L3 handler — **0x0800→IPv4, 0x86DD→IPv6, 0x0806→ARP** (0.11.3). 🎯

## 7. ⚖️ Pros & Cons (of the frame design)

| 👍 Pros | 👎 Cons |
|---|---|
| Fast hardware forwarding (exact-match MAC) ⚡ | Flat MACs → local only, not routable 🗺️ |
| **Self-learning** switches, plug-and-play 🧠 | Broadcasts **flood** the domain 🌊 |
| **FCS** stops corrupt frames early 🧮 | No **correction/retransmit** (relies on L4) 🎲 |
| **802.1Q** multiplexes many VLANs + CoS on one link 🏷️ | Native-VLAN/double-tag = misconfig & attack surface ⚠️ |
| Same frame format 10 Mb→100 Gb (backward-compatible) 🏆 | No TTL → L2 loops are deadly (need STP) 🔁 |

## 8. 🧬 Variants (common → specific)

1. 🟢 **Ethernet II** — EtherType-based, the dominant framing.
2. 🟢 **IEEE 802.3 + 802.2 LLC (+SNAP)** 🔵 — legacy length-based.
3. 🟢 **802.1Q-tagged** — +4 B VLAN tag (trunking basis).
4. 🔵 **802.1ad (QinQ)** — double-tagged (S-tag 0x88A8 + C-tag 0x8100).
5. 🔵 **Jumbo frames** (~9000 B) — DC/storage efficiency.
6. 🔵 **Other L2 framings:** PPP/HDLC (serial), 802.11 (Wi-Fi), MACsec (802.1AE encryption).

> 💡 **Why the frame barely changed in 40 years:** the L1/L2 split lets speeds jump (10 Mb → 400 Gb) while the **frame format stays constant** — swap the PHY, keep everything above. Backward compatibility as a superpower. 🏆

### ISL note (Cisco legacy) 🔵
Cisco's old **ISL** *encapsulated* the whole frame (adding a 26-B header + 4-B CRC) instead of *inserting* a tag like 802.1Q. It's obsolete — **802.1Q is standard**. Know the name; don't use it.

## 9. 🧰 Devices / Protocols at L2 🟢

| Device | Reads | Rewrites |
|---|---|---|
| **Switch** | dest MAC | 802.1Q tag (access↔trunk) + **FCS** |
| Wireless AP | 802.11↔802.3 | bridges framing |
| NIC | full frame | builds/strips |
| Router (L3) | — (peels frame) | **new frame** (new MACs+FCS) |

**Protocols:** Ethernet (802.3), 802.2 LLC, **802.1Q**, STP/RSTP, CDP/LLDP, ARP/NDP.

## 10. ✅ Best Practices (engineer habits)

- 🧠 **Read the MAC table + interface counters** when debugging L2 (`show mac address-table`, `show interfaces`).
- 🏷️ **Match native VLAN on both trunk ends** and avoid VLAN 1 as native → prevents silent merges and VLAN-hopping.
- 📏 **Keep MTU/jumbo consistent end-to-end.** One mismatched hop = drops on big frames.
- 🔁 **Never build an L2 loop without STP** — no TTL means broadcast storms.
- 🧮 **Treat CRC/runt/giant counters as physical.** Bad cable/transceiver or duplex mismatch, not "the app."
- 🎚️ **Use PCP (CoS) intentionally** for voice/video on trunks — and remember PCP 1 < PCP 0.

## 11. 🚧 No-Goes (common mistakes + troubleshooting)

| ❌ Mistake | ✅ Reality / Fix |
|---|---|
| "The 802.1Q tag goes at the end." | It's inserted **between Src MAC and EtherType** (EtherType slot = 0x8100). |
| "There are 4096 usable VLANs." | **4094** (VID 0 and 4095 reserved). |
| "PCP is a clean 0→7 priority ramp." | **PCP 1 (Background) < PCP 0 (Best Effort)** — the quirk. |
| "Native-VLAN mismatch is harmless." | It **merges VLANs** silently and enables **VLAN hopping**. |
| "A switch reads IP addresses." | It forwards on **MAC** (L2); IP is the router's job. |
| "FCS fixes errors." | It only **detects & discards**; correction = TCP (L4). |
| "Broadcast is FF:...:00." | Broadcast is **all ones**: `FF:FF:FF:FF:FF:FF`. |
| "Jumbo just works." | Needs **every hop + both ends** to agree, or big frames drop. |

**🩺 Troubleshooting reflexes:**
- **CRC/FCS** climbing → cable/fiber/transceiver or duplex (physical).
- **Runts/giants** → collisions/duplex (runt) or MTU/tag mismatch (giant).
- Trunk passes some VLANs, not others → **allowed-VLAN list** / native mismatch.
- Random cross-VLAN leakage → **native-VLAN mismatch** or double-tagging.

## 13. 🧪 Practical Tasks (hands-on)

> *Listed briefly; expanded in the lab context later.*

1. **🧬 Dissect a frame (Wireshark).** Expand Ethernet II: read **Dest/Src MAC** (decode the OUI vendor), the **EtherType**, and note preamble/SFD/FCS are usually hidden. → *Frame structure, concretely.*
2. **🏷️ Capture a tagged frame on a trunk.** Find the **802.1Q** tag: read **TPID 0x8100**, **PCP**, **DEI**, **VID**. Compare an **untagged native-VLAN** frame. → *The tag, byte by byte.*

4. **🎚️ Set & verify CoS.** Mark voice traffic PCP 5 on a trunk; confirm the PCP bits in a capture. → *L2 QoS in action.*
5. **🔁 (lab only) Native-VLAN mismatch.** Mismatch native VLANs on a trunk and observe the CDP warning / cross-VLAN behaviour; then fix. → *Why native matters.*
